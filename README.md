# fcastellanos.io

Fernando Castellanos' blog, built with [Jekyll](https://jekyllrb.com) and deployed by Netlify on every push to `master` (build settings in `netlify.toml`). Pull requests get a Netlify deploy preview.

## Writing a post

Add a Markdown file to `_posts/` named `YYYY-MM-DD-slug.md`:

```markdown
---
title: "My Post Title"
date: 2026-10-23 09:00:00 -0700
tags: [ruby, rails]
---

Post body here.
```

Work-in-progress posts go in `_drafts/` (no date in the filename) and are not published. Images go in `assets/img/`.

### Header images

Every post gets a header image, shown above the post, on the home page cards, and in link previews (`og:image`). By default it's a branded title card generated from the post's title, tags, and date, in a light and a dark version. To use your own image instead (ideally 1200×630), add it to the front matter:

```yaml
image: /assets/img/my-post/cover.png
image_alt: "What the image shows"
```

For an illustrated header that matches the site's look, add a module to `scripts/covers/` (see `handing-dependabot-to-an-agent.mjs`), run `npm run covers` to render `assets/img/<slug>/cover-light.png` and `cover-dark.png`, commit them, and set:

```yaml
image: /assets/img/<slug>/cover-light.png
image_dark: /assets/img/<slug>/cover-dark.png
image_alt: "What the diagram shows"
```

The title cards are generated by `npm run cards` (`scripts/generate-cards.mjs`) into `assets/cards/`, which is not committed. Netlify runs it before every build.

## Running locally

```sh
bundle install
npm install
npm run cards
bundle exec jekyll serve --drafts
```

Then open http://localhost:4000.
